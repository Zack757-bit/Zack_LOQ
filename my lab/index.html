Lenovo LOQ 15IRX10 Detailed Overview

Processor (CPU): Intel Core i5-13450HX processor, offering exceptional performance for gaming and multitasking.

Graphics (GPU): NVIDIA GeForce RTX 5050 8Gp series graphics providing stunning visual fidelity and ray-tracing capabilities.

RAM: 16GB high-speed memory. Memory can be fully upgraded and expanded easily.

Storage: Fast 512GB SSD storage. The system supports adding an extra M.2 SSD hard drive for maximum storage capacity.

Manufacturer: Lenovo Group Limited.

Release Date: Latest generation release lineup.

Operating System: Windows 11 Home / Pro compatible.
